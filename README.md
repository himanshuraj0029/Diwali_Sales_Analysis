🪔 Diwali Sales Analysis Using Python

📌 Project Overview

This project focuses on analyzing Diwali sales data using Python to understand customer purchasing behavior, sales trends, and product preferences. The analysis helps identify important business insights that can support better marketing strategies and business decisions.

🎯 Objectives

Analyze sales data during the Diwali festival.

Understand customer purchasing patterns.

Compare sales across genders and states.

Identify customer segments and purchasing preferences.

Visualize key insights using charts and graphs.

Practice data analysis skills using Python libraries.

🛠️ Technologies Used

Python – Programming language

Pandas – Data cleaning and data manipulation

NumPy – Numerical operations

Matplotlib – Data visualization

Seaborn – Statistical data visualization

Jupyter Notebook – Interactive analysis environment
